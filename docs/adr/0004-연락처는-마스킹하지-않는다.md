# 프로필 연락처는 마스킹하지 않는다

Day 5의 가드레일에서는 응답에 들어간 전화번호와 이메일을 `mask_pii`로 가립니다. 하지만 이 시스템에서 임원과 비서가 프로필을 보는 이유는 대부분 참석자에게 연락하기 위해서이므로, 연락처를 가리면 기능이 쓸모없어집니다. 그래서 연락처는 마스킹하지 않고, 대신 **누가 볼 수 있는지**로 보호합니다. 연락처는 임원과 비서에게만 보이고, 관리자는 프로필 자체를 볼 수 없습니다. `mask_pii`는 프로필 응답에 적용하지 않습니다. 로그와 트레이스처럼 사람이 직접 보지 않는 출력에는 계속 적용합니다.
