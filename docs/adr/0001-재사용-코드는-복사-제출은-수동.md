# 재사용 코드는 복사해서 가져오고, 제출은 이 저장소를 원격에 push한다

`sds-ax-training`과 `sds-ax-practice`에서 쓰는 코드(가드레일, 승인 게이트, 계측과 평가, API 서버)는 경로로 참조하지 않고 이 저장소 안으로 복사합니다. 이 저장소만 받아도 외부 경로 없이 그대로 동작하게 하기 위해서입니다. 코드가 중복되는 것은 감수합니다.

처음에는 채점이 `sds-ax-training/miniprj/`와 `[제출] MiniPJT` 커밋으로만 이루어진다고 보고, 제출할 때 손으로 옮길 계획이었습니다. 제출 방식을 확인해 보니(2026-10-23, TASKS 6-2) `mini-pjt` 저장소를 원격(`origin`)에 push하는 것으로 충분해, 손으로 옮기거나 폴더 이름을 `mini-pjt_김상열`로 바꾸지 않습니다. 비밀 값(`.env`)과 실행 중 생기는 파일(`db/`, `chroma_db/`)은 `.gitignore`로 빠지므로, 받은 쪽은 README의 실행 방법대로 `.venv`와 DB, 벡터DB를 새로 만듭니다.
